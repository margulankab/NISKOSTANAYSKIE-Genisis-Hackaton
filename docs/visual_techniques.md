# Memory Worlds visual techniques

| Treatment | Input and implementation | Reviewed result |
|---|---|---|
| Atmospheric perspective | Time sets the key-light direction. Fog draws distant shapes toward the sky color. Matte surfaces remain legible as the background recedes. | The foggy cove separates the shoreline walkway, pier and lighthouse. |
| Framing and visual rhythm | Landmark placement reserves clear approaches. Seeded ground detail stays away from the walking path. Alternating tree silhouettes and warm markers lead the eye. | The park shows the gazebo past the entrance. The pool deck gives the water park a visible dry route. |
| Color derived from the source image | The first photo supplies its dominant color and lightness. The dominant color tints the key light. Composed scenes blend the secondary swatch into decorative material. | The fictional park day uses a warm image and a contrasting muted green. The tense room uses darker, cooler colors. |
| In-world photographic framing | A local texture up to 1,024 px fits inside a frame near the first discovery. The original file remains available in the reveal and ZIP. | The reopened demo preserves the same photograph and excerpt. |
| Music and light | The analyzed 100 ms energy envelope drives a restrained light response during playback. The legacy scene also uses positional and scale cues. Reduced-motion mode suppresses playback-driven motion. | Coastal Light, Still Rooms and Lantern Market provide distinct authorized associations across the five exported days. |

The captures in the local case package are from the playable browser build. The gallery and prompt-world captures are engineering evidence for the separate product track.
