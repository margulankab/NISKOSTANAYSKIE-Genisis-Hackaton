# Рабочие правила Memory Worlds

Этот файл предназначен для будущего корня репозитория. Сейчас он находится в пакете планирования; сначала проверь и адаптируй его к фактической структуре проекта.

## Проект и источник истины

Memory Worlds превращает текст, фотографии и музыку дня в короткую интерактивную 3D-память. Реализация строится из проверяемых данных и фиксированных шаблонов, не из исполняемого AI-кода.

Перед каждой работой:
1. Прочитай этот файл и PROGRESS.md.
2. Проверь код, git и реальные команды проекта.
3. Открой относящиеся к задаче разделы ARCHITECTURE.md.
4. Выбери верхнюю доступную P0-задачу и согласуй критерий приёмки до изменений.

## Продуктовые инварианты

- Текст хранит смысл; фото добавляет подлинный артефакт; музыка влияет на темп и атмосферу.
- Стиль, камера и взаимодействия остаются едиными для всех трёх окружений.
- Gemini возвращает только структурированные данные. Не исполняй, не оценивай и не рендери свободный код из ответа.
- Рендер детерминирован для сохранённых манифеста, seed, версии схемы и правил.
- Фрагменты личного текста должны происходить из записи пользователя, а не выдумываться как реальные воспоминания.
- Название папки содержит 3–7 слов. Архив повторно открывает сохранённый манифест без новой генерации.

## Инженерная работа

- Сначала минимальный вертикальный срез на fixture, затем расширение.
- Проверяй фактические зависимости и скрипты перед добавлением команд в документацию.
- Держи изменения узкими; не добавляй крупные абстракции или P1-идеи без пересмотра сроков.
- После изменений выполняй подходящую проверку и записывай результат. Не заявляй о пройденных тестах, которые не запускались.
- Если схема, endpoint, файл или способ хранения изменился, синхронизируй ARCHITECTURE.md.
- В конце каждой сессии обновляй PROGRESS.md: статус, доказательства, блокеры и следующая задача.

## Безопасность, права и приватность

- Не помещай API-ключи или Supabase service-role secrets в клиентский код, репозиторий и примеры.
- Загружай только разрешённые пользователем фото и аудио; не скачивай поток со стороннего музыкального сервиса.
- Проверяй MIME/размер и авторизованный доступ к медиа; не публикуй личные записи по умолчанию.
- Считай текст, метаданные, изображения и ответ LLM недоверенным вводом.
- Разрешай только перечисленные presets/props/enums; ограничивай строки и числа; запрещай произвольные URLs и координаты от LLM.
- Эмоциональная интерпретация — художественная трактовка, не психологический диагноз.
- Используй модели, музыку и текстуры с понятным разрешением и указывай кредиты.

## Протокол завершения

Кратко укажи: что изменено, где, какие проверки прошли или не запускались, оставшиеся блокеры и следующую приоритетную задачу. Отмечай задачу выполненной только после её критерия приёмки.
