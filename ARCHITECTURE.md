# Memory Worlds — архитектура

> **Статус: предложенная архитектура.** Кодовую базу не проверяли. Пути, маршруты, endpoints и таблицы ниже — target design, не утверждение, что они уже существуют. После инициализации заменять описания фактически проверенными.

## 1. Система и поток данных

Пользовательский браузер (Next.js/TypeScript) принимает дневниковый текст, фото и разрешённую песню/аудиофайл. Клиент может извлечь палитру/яркость фото и доступные аудиосигналы. FastAPI проверяет ввод, передаёт ограниченный мультимодальный запрос Gemini, нормализует результат к MemoryScene и сохраняет ссылки на медиа и манифест через Supabase. React Three Fiber читает только валидированный манифест и строит сцену из фиксированных шаблонов и каталога. Архив открывает сохранённую запись без повторного вызова модели.

Направление: Browser → FastAPI → Gemini → нормализация/Pydantic → Supabase → R3F renderer.  
Граница доверия: всё от пользователя и LLM — недоверенные данные; в движок не передаются исполняемые инструкции.

## 2. Планируемый стек и зоны ответственности

| Слой | Предлагаемая технология | Ответственность |
|---|---|---|
| UI и роутинг | Next.js + TypeScript | Форма, состояния, архив, просмотр |
| 3D | Three.js через React Three Fiber + Drei | Детерминированная сцена и взаимодействия |
| API | FastAPI + Pydantic | Проверка ввода, Gemini, нормализация, storage orchestration |
| AI | Google Gemini | Смысловой разбор, кандидаты объектов, короткие фразы и title |
| Данные | Supabase Postgres + Storage | Манифест, архив и закрытые ссылки на медиа |
| Аудио | Web Audio API при доступном/разрешённом сигнале | Мягкие реакции сцены; fallback — официальная ссылка |

Команды, версии, deployment и env имена уточнить по реальному репозиторию. Секреты хранить только на сервере.

## 3. Планируемые страницы и дерево

- / — вход в продукт.
- /create — форма дня.
- /archive — сохранённые сцены.
- /memory/{id} — открытие существующего манифеста.

Предлагаемая структура находится в TASKS_BY_FILE.md. Не создавать пути заранее без конкретной задачи; дерево адаптировать к scaffold.

## 4. Схема сцены

Каноническая структура — версионированный MemoryScene, общий по смыслу для TypeScript и Pydantic.

| Группа полей | Содержание |
|---|---|
| schemaVersion, seed, title, date | Версия, повторяемость, название 3–7 слов, дата |
| source | entryId, photoIds, song reference/audio id |
| mood | primary, warmth, energy, tension, valence в диапазоне 0–1 |
| environment | preset park/room/city, season, timeOfDay, weather |
| photos | palette, lightness, textureMood |
| music | источник, измеренный профиль либо unknown/null |
| artifacts | id, тип из каталога, interaction, photoId, подтверждённый excerpt |
| narrative | короткие arrival и ending |
| explanation | реальные правила, применённые движком |

Генератор не должен выпускать Three.js-код, произвольные URLs, shader source, неподконтрольные координаты или неограниченные типы объектов. Ограничивать enums, длины, число артефактов и числа; при ошибке использовать fixture/fallback. Не выдавать предположения о психологии за факт.

## 5. Предлагаемый API

| Метод и путь | Назначение | Планируемый контракт |
|---|---|---|
| GET /health | Проверка сервиса | Readiness без секретов |
| POST /api/assets/upload | Медиа | Проверка типа/размера/доступа; возврат opaque media ID |
| POST /api/memories/generate | Черновая генерация | Текст + медиа refs + песня → валидированный draft manifest и объяснения |
| POST /api/memories | Сохранение | Сохраняет финальный manifest; возвращает ID |
| GET /api/memories | Архив | Только записи текущего владельца/демо-сессии |
| GET /api/memories/{id} | Повторное открытие | Возвращает сохранённый manifest и media refs; Gemini не вызывается |

Предварительно выбран draft-then-save поток. Если реальный проект требует атомарной генерации/записи, поменять на один маршрут и обновить все документы.

## 6. Предлагаемая модель хранения

- memories: id, owner/session ref, date, title, original_text, song reference/description, manifest_json, schema_version, rules_version, seed, timestamps, optional preview.
- memory_assets: id, memory_id, kind, storage_path, content_type, permission/license note, created_at.
- Storage закрытый по умолчанию; доступ подписанный или авторизованный.
- Для личных данных использовать Auth/RLS. Если демо анонимное, явно ограничить и пометить demo-only; не включать публичный свободный write/read.
- Загрузка должна быть проверяемой и по возможности идемпотентной.

## 7. Сцена и повторное открытие

Движок резолвит preset, palette, lighting, catalog props, фото-текстуры, темп, взаимодействия и финальный beat. Эмоциональные значения смешиваются с контекстом текста, фото и доступной музыки: один цвет не определяет настроение. Три шаблона используют одну композиционную грамматику, а различаются параметрами и объектами. Сцена хранит seed и версии схемы/правил.

Состояния пользователя: arrival → explore → reveal artifacts → emotional ending → archive. Завершение преимущественно запускается взаимодействием; таймер допустим только как мягкий fallback для демо.

## 8. Fallback и безопасность

- Gemini недоступна/JSON некорректен: нормализация с ограниченным retry, затем известная fixture.
- Нет аудиосигнала: официальный song link, description или null-профиль; не заявлять измеренный BPM.
- Нет фото: ясная ошибка/fixture-путь, не придумывать пользовательскую фотографию.
- Нет WebGL: объясняющее сообщение и по возможности статичный preview.
- Истёк media URL: контролируемая ошибка и возможность повторить получение.
- Старый schemaVersion: намеренная миграция или явная ошибка, не silent reinterpretation.
- HTML текст экранировать; API-ключи, приватные записи и Supabase service-role только на сервере.

## 9. Журнал решений

| Решение | Причина | Пересмотреть, если |
|---|---|---|
| R3F вместо Godot | Встраивается в React/Next, снижает интеграционный риск спринта | Команда уже имеет готовый Godot pipeline |
| Окружения park/room/city | Достаточное разнообразие без генерации произвольного мира | Три сценария готовы раньше срока |
| Схема и шаблоны вместо исполняемого AI-кода | Безопасность, повторяемость, объяснимость | Не пересматривается в этом спринте |
| Fixture путь не зависит от LLM | Демо остаётся рабочим при сбое сети/модели | Не пересматривается в этом спринте |
